## 2. 鉴权与会话

- 会话为 **HttpOnly Cookie**（30 天）；口令 PBKDF2-HMAC-SHA256（20 万迭代+盐），服务端不存明文。
- 端点：`POST /api/auth/login`、`POST /api/auth/register`（可带 `invite`）、`POST /api/auth/logout`、`GET /api/me`、`GET /api/state`（`signed_in`）。
- 前端启动顺序：匿名 `GET /api/state` 取 `policy`（登录卡展示注册赠送/邀请码）→ `GET /api/me` 判 `signed_in` → 进入应用；未登录停留登录页。
- 会话失效：轮询 `refresh()` 见 `state.signed_in === false` → `location.reload()` 回登录页。
- **权限边界（后端已实现，前端依赖，勿放宽）**：
  - `workers[]` 的 `hostname/address/ipv6/disk_free_mb/device_id/earned*/billed*` 仅 owner 可见（`hub.go:2113-2125`）；他人节点只露规格/价格/信誉。
  - `jobs[]` 仅返回当前用户自己的任务（`hub.go:2130-2136`）。
  - 会话仅 buyer/seller 可读（`offers.go:466`）。
  - `GET /api/models/usage` 仅平台自营账户，普通用户 403 → 前端降级为提示文案，不拖垮整页。

## 5. ComfyUI 工作台集成（原生复用未改；React 副本打补丁）

## 6. 前端轮询与差量渲染模型（后端负载特征）

- 原生：登录后 `GET /api/state` **每 1s**；列表做 JSON 签名比对，**仅数据变化才重绘**，表单输入不被冲刷。
- React：store（Context）登录后 `/api/state` 每 1s + `/api/contribution` 每 5s；各视图自管 interval；靠 React reconciliation 保留受控/非受控输入，表单不被冲刷。
- 各视图节流（两版一致）：offers 5s、vm 4s、ledger 5s(钱包)/10s(总览)、forum 10s、conversations 5s、会话消息 3s、pending 5s；`/api/estimate` 仅表单变化时 250ms debounce。React 的 api 视图在进入/切换 tab 时加载、mutation 后刷新（无周期轮询）。
- React 新增纯前端行为（无需后端改动）：市场 saved view（localStorage `ss-react-market` 记忆 q/cat/sort）、云主机上下架乐观更新+失败回滚。
- Agent 指令层（纯前端，无新增后端端点）：`web-react/src/agent.js` 与 `internal/hub/web/assets/agent.js` 为同一套意图规则。试聊升级为 agent 聊天：有对话后输入框沉底、消息在上方滚动并自动滚到最新；识别为指令时复用既有端点/导航/预填（生图生视频预填、市场搜索、充值、创建密钥、查余额/任务/节点），识别不了回落 `POST /api/models/try` 模型对话。
- 负载提示：`/api/state` 每秒全量序列化 `workers[]+jobs[]`（含 owner 私有字段），节点/任务多时开销显著 → 见 7.P0。

**`/api/state` 条件请求**：响应返回强 `ETag`、`Cache-Control: private, no-cache`、`Vary: Cookie`；带匹配的 `If-None-Match`（支持 `W/`、多值列表、`*`）时返回 `304` 且无响应体。ETag 由响应内容 + 当前 viewer ID 计算，`now` 不参与（否则每秒必变）；`workers[].since` / `parked_sec` 按 5 秒分桶，所以空闲池能命中 304，倒计时最多滞后 5 秒。CORS 已允许 `If-None-Match` 并暴露 `ETag`。前端无需改动：浏览器缓存自动完成条件请求，命中时 `fetch` 拿到的是缓存的 200 响应体。

**列表通用参数**（仅显式传入时生效）：`limit`、`offset`（`cursor` 是数字 offset 的别名）、`q`。带上任一参数后响应额外返回 `total`、`offset`、`limit`；不传任何参数时，响应字段与改造前完全一致。

|---|---|---|
| `GET /api/offers` | 100 / 200 | `q` 搜标题、简介、配置、版块、卖家名 |
| `GET /api/forum/posts` | 100 / 200 | `q` 搜标题、正文、作者名 |
