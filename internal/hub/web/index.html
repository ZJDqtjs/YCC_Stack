星栈算力

把闲置的机器接进来，按视频秒计价；用别人的机器转码，按实测用量结算。

口令以 PBKDF2-HMAC-SHA256（20 万次迭代 + 随机盐）存储，服务端不保存明文； 会话为 HttpOnly Cookie，有效期 30 天。

Billing计价规则

预扣 = 视频总时长 ×「满足全部硬约束的最贵在线节点」单价：宁可多扣，也不让任务中途故障转移 到更贵机器时平台倒贴。实际按每个分片「视频秒数 × 派发时锁定的单价」结算，差额在完成或失败时退还。

MoE分布式 / MoE 部署

        

          MoE 的专家权重远大于单卡显存，常见做法是把专家放在 CPU 内存、注意力层留在 GPU：
          llama.cpp 的 --n-cpu-moe N 控制放进 CPU 的专家层数。多机则每台跑
          rpc-server，主节点用 --rpc 聚合显存，对平台仍是一个标准端点。
          vLLM 多卡用 --tensor-parallel-size；Ollama 监听 0.0.0.0 后直接填地址。
