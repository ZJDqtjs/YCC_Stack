Host一键把这台机器接入云主机

      

        下载脚本 → 拷到要出租的电脑上运行（Windows 双击 .cmd，Linux/macOS 执行 sh 脚本名）→
        脚本会检查/引导安装 QEMU，再启动 Agent 并自动绑定到你的账户。启动后回到本页刷新，就能发布配置。

      

        

        

        

      

      

        

        

        

      

      

        

        

      

      
routed 需要 Linux 网桥和 root/CAP_NET_ADMIN；不填网桥就是最省事的 slirp 模式。
        云主机需要放行 IPv6 入站 TCP 5900-5999（控制台）、20000-29999（SSH/自动端口）以及配置里显式填写的其它端口；
        Windows 另需启用「Windows Hypervisor Platform」，Linux 需当前用户可读写 /dev/kvm。

      

      

      

      
首次运行会下载约 10MB Agent；没装 QEMU 时脚本会给出安装命令并询问是否代装。
        脚本是一次性的，30 分钟内有效；启动后保持窗口，关掉即停止提供算力。

Provider Nodes
我的节点

      
把闲置机器接进来赚算力点：下载节点包，解压后直接双击 exe 即可。一台电脑只对应一个节点，收益与信誉连续累计；贡献只统计校验通过的任务分片和已结算的云主机租用。

    

  

  

    1填写机器参数
    2下载节点包
    3在那台机器上运行
    4自动开始接单
  

  

    

      
Provider一键提供算力

      

        填好参数后下载节点包，解压后双击其中的 exe，这台机器就会以你的账户身份加入算力池并开始接单。
        关掉窗口即停止；重复启动只会回到原来那个节点。

      
      
      

        

          

        

      

      

        

          

        

          

      

      

      

      

      

        高级用法：手动运行 Provider Agent

Contribution贡献概览

    
卖家贡献（账户维度）= 账本中该账户全部收益流水之和；节点贡献（设备维度）= 单台机器已结算的任务与云主机算力。两者是同一本账的两个视角，不是两笔钱。

    
正在读取贡献账目…

    
「其它收益」= 卖家贡献 − Σ 当前名下节点贡献，包含模型上游收益、已删除节点的历史收益和升级前的旧账。任务分片校验通过才发收益，云主机按租用时长结算、平台留 10%；在线挂机不产生贡献。模型上游收益按售价的 90% 记入上游 owner 账户、10% 留作平台撮合费。
