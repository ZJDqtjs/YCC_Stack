网络不通怎么办？

          
ComfyHub 在 Azure，你的电脑在 NAT 后面时，给 agent 一条被访问的通道。

          
最省心：Tailscale
几台电脑加入同一 tailnet，填 http://100.x.x.x:端口。

临时演示：SSH 反向隧道
ssh -N -R 8190:127.0.0.1:8190 azureuser@20.24.210.119
然后在本页填 http://127.0.0.1:8190。

也可以：Cloudflare Tunnel，把生成的 https 地址填进来。
